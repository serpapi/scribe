# Scribe

Scribe is a tool for converting YouTube videos into eBooks that you can read on any device. You can install Scribe as a command-line application or self-hosted web service.

Scribe uses the [YouTube Video API](https://serpapi.com/youtube-video-api) and [YouTube Video Transcript API](https://serpapi.com/youtube-video-transcript) from [SerpApi](https://serpapi.com/) for retrieving video information, and [Pandoc](https://pandoc.org/) for file exports.

**Features:**
- Save books as ePub, HTML, RTF, or TXT format
- Chapters from YouTube are saved as book chapters
- Timestamp links for opening a given section in the original video
- Transcribed text comes directly from YouTube, and is not summarized or modified

This is still in early development!
